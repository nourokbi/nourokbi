## About Me

I build web apps from the interface down to the API. On the frontend I use React, Next.js and TypeScript, and on the backend ASP.NET Core or Node.js with PostgreSQL and SQL Server. My GIS background means a lot of my work involves maps and location data, and I enjoy turning data into screens people can actually use.

- Currently going deeper into **Node.js, NestJS and Next.js**
- Learning **automated testing** and **cloud deployment**
- Open to working on **web apps**, **GIS projects** and **open-source contributions**
